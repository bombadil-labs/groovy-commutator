## A binary field derived from the quotient

An arbitrary integer fiber rank padded to n bits is a bookkeeping encoding,
not automatically a translation-covariant lattice field. Instead attempt
an exact equivariant embedding of C over O into O times {0,1}^n.
Q has n microscopic sites in BOTH arms; Z still has its declared block origin.

For G use the one-site cyclic translation group. For Z use two-site
translations (block alignment); do not claim one-site covariance for Z.
For each orbit of visible fields choose its least integer visible field.
Its stabilizer H acts on the future classes in that visible fiber.
Enumerate those H-orbits and the H-orbits of n-bit words. Match each class
orbit injectively to the first unused binary-word orbit of exactly the same
length. Reuse codes across distinct visible orbits. Propagate assignments
by translations. This preserves exactly C and no additional distinctions.

If demand exceeds supply for any orbit length, save visible field, stabilizer,
demand/supply counts and class representatives as an exact obstruction to
THIS minimal equivariant binary embedding. It does not rule out an
overrefined binary augmentation. Otherwise save all Q(X) and verify:

1. Q is constant on C classes and (O,Q) has exactly partition C;
2. Q commutes with the declared translations;
3. equal (O,Q) has equal next (O,Q), including Q's own update.

This yields a finite-ring field and global lookup law, not an infinite-line
local law. Test the resulting deterministic encoders for repetition
compatibility at all divisibility pairs among the frozen widths. A conflict
refutes a single size-independent encoder for this construction.
Test radius 0,1,2,3 readouts of next (O,Q), exhausting all states and using
covariance to cover every site: microscopic radii for G,Q; macro radii for
Z plus the two Q bits per block. Retain exact collision pairs and also test
joint tables across widths. Passing is only a bounded necessary check.
Do not optimize codes after seeing locality or repetition failures.
