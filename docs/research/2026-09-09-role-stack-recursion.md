# The zero-guard role stack closes across dimensions, but not yet recursively

The derivative-completed lift suggests representing three equal-size semantic roles in one next-dimensional totalistic rule table:

\[
L(r,s,\delta)=[r\mid s\mid\delta].
\]

Three frozen tests now locate exactly how far the simplest spatial realization of that idea goes.

## 1D -> 2D: one nonconstant witness

The [role-stack protocol](protocols/role-stack-closure-20260909.md) exhausts 1,788 one-data-row / uniform-guard templates with transverse periods 3 through 8, every fixed transverse drift, all eight one-dimensional center-independent totalistic rules, and all eight predecessor states.

There is no universal template. Only source Rule 0 and source table

\[
(0,1,0),
\]

which is ECA Rule 90, have any successful template.

Rule 90 succeeds exactly once per tested period: a data row in an otherwise all-zero transverse background, with zero drift. The result is exact for the declared finite family.

The mechanism is simple. The data row is flanked by zero rows, so every data cell addresses the first rule block and evolves by Rule 90. On the width-three lower ring, every Rule-90 image has population 0 or 2, and the corresponding table entries are both zero, so adjacent guard rows remain zero.

Crucially, every successful Rule-90 trajectory addresses only role band zero. The `state` and `derivative` blocks are present in the lifted table but dormant.

## 2D -> 3D: the same geometry has a 29-rule family

The preregistered [scale-up](protocols/role-stack-scaleup-20260909.md) freezes the minimal period-three geometry

\[
E(s)=[s,0,0]
\]

and applies it to all 512 two-dimensional center-independent totalistic rules on the complete `3 x 3` lower state space.

Exactly

\[
\boxed{29/512}
\]

rules close for every lower predecessor state.

Write the nine-bit rule as `r[0]...r[8]`. The successful family has an exact algebraic characterization:

1. `r[0]=r[8]=0`;
2. no adjacent entries are both one;
3. for every rising edge `r[p-1]=0, r[p]=1`, the reflected entry `r[9-p]` is zero.

To see why, let a predecessor have population `P`. On the side-three lower torus the next population is

\[
K_P=(9-P)r_P+P r_{P-1}.
\]

The neighboring zero slice remains zero exactly when the lifted table entry at `K_P` is zero. The four possibilities for the adjacent pair `(r_{P-1},r_P)` reduce this condition to the three constraints above. The verifier checks the direct structured 3D update against the population criterion on every source transition.

This is already a dimension-uniform *form* of closure: the same zero-background geometry works nontrivially at successive dimensional interfaces.

## The first recursive chain fails on changing transitions

The decisive follow-up freezes the 29-rule second-lift domain and applies it to the **actual 2D rules generated by the first 1D lift**.

For every one-dimensional source transition,

\[
R_2=[r\mid s\mid\delta]
\]

is tested for membership in the frozen 2D -> 3D closure family.

No one-dimensional source rule has uniform two-step closure.

For the Rule-90 source, only two of eight predecessor states produce a second-liftable `R_2`:

- `000`, giving lifted rule 2;
- `101`, giving lifted rule 42.

Both are fixed states of the width-three Rule-90 dynamics, hence both have

\[
\delta=0.
\]

So the first apparent `1D -> 2D -> 3D` chain survives only where nothing is actually changing. This is an informative failure: **the simple zero-guard ladder stops precisely when derivative information would have to become dynamically active.**

## What this changes

The next search should not add arbitrary guard patterns. The frozen one-data-row census already explored those through period eight.

The smaller structural question comes first: can the three equal-size roles `r`, `s`, and `delta` update one another through the three available rule blocks in a fixed, rule-blind role cycle? If no such local role algebra exists even before spatializing guards, this derivative-completed architecture cannot recursively close without adding another operation or channel.

If such an algebra exists, its selector pattern can then be realized geometrically and tested across dimensions.
