## Question

Do the 0D→1D and 1D→2D shell constructions actually instantiate one local law-to-state selector semantics, once physical role overlap and geometry are made explicit, or is the apparent `2=2`, `8=8` progression only a storage coincidence?

## Answer

Within the frozen local architecture, the same multiplexer semantics works at both bottom rungs, but the physical resource structure changes sharply.

At Z0, the one address cell and two program cells fit disjointly in `(L,C,R)`. At Z1, three address roles plus eight program roles cannot fit disjointly in a nine-cell Moore patch. The accepted selector works because `W` and `E` are deliberately dual-role: each is simultaneously a current address bit and a stored truth-table bit. The exact lower bound

`max(0, k + 2^k - |P|)`

is 0 for Z0 and 2 for Z1, and both constructions attain it.

The predeclared Gray-code geometry does **not** add a matching nontrivial ECA symmetry. Across all 16 distinct frozen Gray-family layouts, the induced square-shell `D4` address actions intersect the ECA group generated by left/right mirror and address complement only at the identity. That negative result agrees with the pre-run cycle-type and antipode proof.

All frozen P1–P8 verdicts pass. This is an exact local base-case audit, not a repeated dynamical dimensional lift.

## Exact results

### 1. Complete 0D floor and commutator control

The complete binary unary rulespace embeds center-only as ECA

`{0, 204, 51, 255}`.

All four are affine. Under the repository's already accepted Groovy-commutator convention, exhaustive five-cell replay gives the expected constant responses:

| ECA | unary map | Groovy response |
| ---: | --- | ---: |
| 0 | constant 0 | 0 |
| 204 | identity | 0 |
| 51 | NOT | 1 |
| 255 | constant 1 | 1 |

Each value is constant over all 32 five-cell windows.

### 2. Minimum role overlap is 0, then 2

For a single-layer selector with `k` address roles, `2^k` program roles, and `|P|` physical sites, at least

`max(0, k + 2^k - |P|)`

roles must overlap.

- Z0: `k=1`, `|P|=3`, minimum overlap 0; attained.
- Z1: `k=3`, `|P|=9`, minimum overlap 2; attained exactly by `W` and `E`.

This is a capacity fact about this declared shell architecture. It is not an intrinsic-dimensional lower bound.

### 3. Local selector structure agrees on every frozen layout

Both Z0 orientations pass every physical three-cell patch. Each selector is degree 2 and all three physical inputs are essential.

The Gray-family generation produces 16 distinct Z1 layouts after the frozen `D4`/address-complement deduplication. For every layout and all 512 Moore patches:

- scalar and packed selector evaluators agree;
- truth-table Möbius ANF and symbolic multiplexer ANF agree;
- all 9 physical inputs are essential;
- algebraic degree is exactly 4;
- exactly 6 quartic terms remain.

The Gate-1 reviewer correctly noted that degree `k+1` and full essentiality are generic multiplexer facts. They are not evidence for a privileged layout or a new dimensional law. The six quartic terms are the non-generic local fingerprint here: six program sites are independent of the address variables while the two dual-role sites `W,E` lower their corresponding terms to degree at most three. This quantity is also layout-independent inside the frozen family.

### 4. The Gray geometry does not realize the familiar ECA symmetry group

The protocol froze a negative prediction after the first review exposed the original positive covariance bet as either tautological or impossible.

ECA mirror has cycle type `1^4 2^2`, while nonidentity square-shell reflections on the eight shell cells have two fixed cells. Address complement and mirror-complement have cycle type `2^4`, leaving the shell half-turn as the only possible `D4` candidate. The reference Gray layout's antipodal address pairs are neither complement nor mirror-complement pairs, and the mismatch is preserved by the frozen dihedral/complement orbit.

Enumeration confirms the theorem: all 16 frozen layouts have identity-only intersection between induced shell `D4` address permutations and the ECA group `<M,C>`.

This is a negative geometry result. It does not show that no other law/state geometry can be useful.

### 5. Rule 51: parity is real, but it is not the exclusion mechanism

For center-only laws, the accepted ordered-axis constructor composes the unary map once per axis, giving `f^d`.

- identity remains identity;
- constants remain their constants;
- rule 51 / NOT alternates with dimension parity.

But rule 51's absence from the accepted exact-replication family is explained separately. The appended-axis interface map is `u_51=NOT`, which fixes no attainable output bit. The parity of `f^d` is a corollary of the lifted dynamics, not the reason the interface fails.

### 6. The 16-bit next-rung number remains tightly scoped

The accepted editable-routing family stores `d` eight-bit routing tables, so its native 2D tuple uses 16 routing bits. Sixteen is below the 26 cells of a 3D radius-one outer shell.

This is **not** compression of an arbitrary 512-bit 2D rule table. It says nothing by itself about a valid 3D shell interpreter, total physical storage, unique geometry, or a recursive arbitrary-rule tower.

## What changed conceptually

The useful result is not that the Gray-code shell reveals a hidden geometric isomorphism; it does not. The useful result is that the same local selector semantics survives the first two rule/state cardinality matches while its physical role accounting changes from disjoint to necessarily overlapping.

That makes the overlap itself a cleaner object for later work than raw coordinate count. It also motivates the separately frozen relational-rank follow-up, which asks about translation directions available to a state family versus displacement directions actually used by a law. That follow-up is independent work and is not evidence supplied by this unit.
