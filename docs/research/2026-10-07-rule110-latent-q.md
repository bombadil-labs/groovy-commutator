# The exact latent complement exists on tested rings, but retains almost the source

Date: 2026-10-07. Evidence: exhaustive finite computation with all-time
finite-domain certificates; algebraic quotient bound. Authored by: Codex
(OpenAI). Reviewed by: none.

We derived the missing coordinate from future equivalence instead of guessing
another local feature. **For the full Rule-110 source ensembles on every even
ring from 6 through 18 cells, any autonomous representation retaining current
parity and Groovy must distinguish every source except two pairs.** The
previous nearly microscopic local repairs were already as compressive as any
possible autonomous augmentation on the overlapping tested rings.

This is a stronger finite-domain negative than failure of a feature grammar.
It is not an infinite-line theorem or a statement about every source prior.
A binary latent Q can be constructed on these same microscopic lattices,
with translation covariance and autonomous whole-field evolution. The
compression gate fails because the minimal sufficient joint state is nearly
the source, not because a binary field lacks room.

## Contract and the distinction we actually quotient

The [frozen protocol](protocols/rule110-latent-q-20261007.md) fixes Wolfram
Rule 110, arbitrary periodic binary sources, uniform source prior, no burn-in,
and epoch map F=H^2. Both the G-only and parity/G arms use this same cadence.
For Rule 110, centered and uncentered Groovy agree:

\[
G(X)=H(X)\oplus H^2(X)\oplus H(X\oplus H(X)).
\]

The primary observation is Z=(P,G), where P_j=X_{2j} XOR X_{2j+1} and G
retains every microscopic site. Secondary O=G and control O=P keep separate
future-equivalence relations. Q always has n microscopic binary sites;
it is not one bit per parity block. The block origin in Z is fixed.

For each observation, define

\[
X\sim_k Y\quad\Longleftrightarrow\quad
O(F^tX)=O(F^tY)\text{ for }0\le t\le k.
\]

The evaluator refines C_{k+1}=compress(C_k,C_k composed with F), starting
at C_0=O. A stable partition, with equal current classes having equal next
classes, is an exact certificate for every future epoch on that ring.
It is not merely a finite observation horizon. Neither these labels nor
their depth are a minimum online suffix-memory length.

Let R(X) be ANY deterministic autonomous augmentation retaining O, with any
alphabet, locality, coding scheme, or number of fields. Equal R implies equal
O now and, by autonomy, at every later time. Therefore R refines C_infinity:

\[
H(X\mid R)\le H(X\mid C_\infty).
\]

This elementary bound is why the quotient answers the compression question
before any search for Q. It applies to the fixed finite source family and
prior; it is not a distribution-free coding-rate theorem.

## Constructing Q in the same binary configuration space

For each visible-field translation orbit, choose a representative visible
field. Its stabilizer acts on the future classes above it and on n-bit words.
An injective equivariant assignment exists exactly when each class-orbit
length has at least as many available binary-word orbits of that length.
The construction assigns those orbits in fixed integer order, then propagates
by translations. Codes are reused over different visible fields.

Every tested G and (P,G) quotient passes that capacity test. The saved arrays
define the actual operator

\[
Q_n(X)=q_n(C_\infty(X))\in\{0,1\}^n.
\]

The induced update is an explicit finite lookup: decode (O,Q) to its unique
class, follow the saved class successor, and read its O and Q. Exhaustive
checks verify the whole joint update, including next Q; no source oracle is
required at runtime once this finite table is built.

The G construction commutes with one-site shifts. The (P,G) construction
commutes with two-site shifts, respecting the parity block origin. No
one-site covariance of that blocked observer is claimed. These are exact
minimal augmentations: (O,Q) has exactly the future partition and introduces
no unnecessary distinctions inside one future class. Q itself need not be
independent of O, sparse in space, or optimized for marginal entropy.
