## 1. The transformations and their costs

For each linear rule `ψ ∈ {0, 60, 90, 102, 150, 170, 204, 240}` the observation `π_ψ(S) = F_ψ(S)` at cadence one. Each is XOR-linear, so its fibers are the cosets of `K_ψ(n) = ker π_ψ` on the `n`-ring, and closure of `F_r` under `π_ψ` holds iff `F_r(S ⊕ k) ⊕ F_r(S) ∈ K_ψ(n)` for every state `S` and every `k ∈ K_ψ(n)` (Research022's factor existence, restated for a linear map). Costs, per observation and ring: information lost is `log₂|K_ψ(n)|` bits per ring; forward radius 1 for all but `204` (0) and `0`; no local inverse where the kernel is nontrivial.

Definitional facts, verified before freezing from the rule tables and not counted as results: `K_204 = K_170 = K_240 = {0}` (bijective); `K_0` is everything; `K_60 = K_102 = {0ⁿ, 1ⁿ}`; `K_90 = {0ⁿ, 1ⁿ}` for odd `n` and the four period-2 patterns `{0ⁿ, 1ⁿ, (01)*, (10)*}` for even `n`; `K_150 = {0}` unless `3 | n`, when it is `{0ⁿ}` plus the three period-3 patterns `(011)*, (101)*, (110)*`, and never contains `1ⁿ`.

Refinement chain and `h_*`: Research023's definitions unchanged, now over cosets rather than pairs: `R_0` identifies states in the same `π_ψ`-fiber, `R_{t+1} = R_t ∩ F_r^{−1}(R_t)`, and `h_*` is the least `h` with `R_h = R_{h+1}` (equivalently, the least `h` such that the observed word of length `h + 1` determines the next observation). Computed by exact partition refinement on the full state space, terminating at the first stationary step; no step bound is needed.

## 2. Frozen predictions

- **E1 (affine rules close under every linear observation; theorem control).** For all 16 affine rules `r`, all eight `ψ`, and all `n ∈ {6, 7, 8, 9, 10, 11, 12}`, `F_r` is closed under `π_ψ`. Proof: `F_r(S ⊕ k) ⊕ F_r(S) = M_r k`, and `M_r` is a polynomial in the shift, as is `π_ψ`, so they commute and `π_ψ M_r k = M_r π_ψ k = 0`. The run is a control.
- **E2 (the trivial observations).** For `ψ ∈ {204, 170, 240}` all 256 rules are closed at every `n` (injective observation); for `ψ = 0` all 256 are closed (constant image); for `ψ = 150` at `n ∈ {7, 8, 10, 11}` all 256 are closed (injective there). Definitional, listed so the verifier scores them.
- **E3 (the complement-kernel observations).** For `ψ ∈ {60, 102}` at every `n ≥ 6`, and for `ψ = 90` at odd `n ∈ {7, 9, 11}`, the closed set is exactly the fifth unit's 32 constant-complement-response rules, because the kernel is `{0ⁿ, 1ⁿ}` and the fifth unit's argument applies verbatim (for `60`, by reflection of `102`).
- **E4 (rule 90 on even rings).** For `ψ = 90` at `n ∈ {6, 8, 10, 12}` the closed set `X_90(n)` satisfies `AFFINE ⊆ X_90(n) ⊆ CLOSED_32` (the kernel contains `{0ⁿ, 1ⁿ}`, so closure implies constant complement response; E1 gives the lower bound), and it is the same set for all four even rings. Which of the 16 nonlinear constant-response rules survive the period-2 kernel is reported, not predicted.
- **E5 (rule 150 on rings divisible by 3).** For `ψ = 150` at `n ∈ {6, 9, 12}` the closed set `X_150(n)` satisfies `AFFINE ⊆ X_150(n)` and is the same set at all three rings; no containment in `CLOSED_32` is predicted, because `1ⁿ ∉ K_150`, so this observation does not test the complement response at all. Whether `X_150` contains rules outside `CLOSED_32` is reported; if it does, the constant-complement-response criterion is shown to be specific to observations whose kernel contains `1ⁿ`, which is the unit's question.
- **E6 (history census).** For every `ψ`, `n` and non-closed rule, `h_*` by exact partition refinement; `h_* = 0` exactly on the closed set (the shared closure account's identity). For `ψ ∈ {60, 102}` and for `ψ = 90` at odd `n`, `h_*` equals the sixth unit's certified depth (0 for the 32, 1 for 216, 2 for the eight `{22, 73, 104, 109, 146, 151, 182, 233}`), for `102` by identity and for `60` by reflection (the depth-2 set is mirror-closed) and for `90` at odd `n` because its fibers are then the complement pairs. No prediction on the magnitude of `h_*` for `90` at even `n` or for `150` at `3 | n`; reported per rule and per ring.
- **E7 (symmetries).** Every closed set and every `h_*` table is invariant under complement conjugation (`π_ψ(¬S) = π_ψ(S) ⊕ F_ψ(1ⁿ)`, a constant, so complement maps fibers to fibers) and, for the reflection-symmetric `ψ ∈ {0, 90, 150, 204}`, under reflection; for `60 ↔ 102` and `170 ↔ 240` reflection exchanges the tables.

## 5. Protocol review record (2026-09-11, before implementation)

Codex reviewed revision `eb7d2f1` and confirmed the four requested points: E1 is sound because on a periodic `n`-ring the linear part of an affine rule and every linear observation are circulant operators, polynomials in the ring shift, hence commuting, and the affine bias cancels in the response; E3 transfers because rules 60, 102 and 90 on odd rings have the same kernel and therefore the same fiber relation, so the fifth unit's classification applies directly, with the `n ≥ 6` witness embedding intact (reflection is a control, not the reason); the "same set across rings" clauses of E4 and E5 stay frozen as falsifiable predictions, to be reported as failures if they fail rather than weakened; the coset partition-refinement definition of `h_*` matches Research023 (`R_h` is equality of the observed word of length `h + 1`; nothing requires two-element fibers), and observations with the same fibers share the entire refinement chain, not only the closed set. E2 and E7 were found consistent, and the artifact plan matches the two-tier replay policy.

Binding wording caution for the note: if rule 150 admits closed rules outside the 32, that shows constant complement response is not necessary for closure under this kernel-lacking observation; it must not be broadened into a characterization of all observations whose kernels omit `1ⁿ` without a separate theorem. Material changes to observations, ring domain, predictions, scoring or artifacts require renewed review.
