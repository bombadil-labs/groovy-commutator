# Protocol: does the same role-stack operator close twice?

Date: 2026-09-09
Status: preregistered before evaluation

## Question

The frozen role-stack geometry has now produced:

1. a nonconstant 1D -> 2D witness for center-independent totalistic rule `(0,1,0)` (ECA Rule 90), and
2. an exact 29-rule closure family for the same zero-guard geometry at 2D -> 3D.

The first true recursive question is whether the **actual 2D rules generated by the first lift** lie inside that 29-rule second-lift domain.

## Source family

Use all eight 1D center-independent totalistic rules, with three-bit tables `r` indexed by neighbor count `0..2`.

For every predecessor state `p` on the complete width-three ring, compute

\[
s=F_r(p),\qquad \delta=p\oplus s.
\]

The first lifted 2D totalistic rule is

\[
R_2=L(r,s,\delta)=[r\mid s\mid\delta].
\]

This produces up to eight lifted rules per source rule, with duplicates retained in the trajectory accounting but canonicalized for the distinct-image summary.

## Frozen second-lift criterion

Do not search any new 2D -> 3D geometry.

Use exactly the algebraic zero-guard closure condition obtained in the preregistered scale-up checkpoint for a nine-bit 2D rule `q`:

- `q[0] = 0`;
- `q[8] = 0`;
- no adjacent entries `q[p-1], q[p]` are both one;
- for every rising edge `q[p-1]=0, q[p]=1`, the reflected entry `q[9-p]` is zero.

The implementation must also cross-check membership against the exact 29-rule list from the scale-up result.

## Primary recursive criterion

A 1D source rule has **uniform two-step role-stack closure** iff for every one of its eight predecessor states, the generated rule `R_2` belongs to the frozen 2D -> 3D closure family.

Record also:

- how many predecessor transitions produce a second-liftable `R_2`;
- the distinct first-lift image rules;
- which distinct images are second-liftable;
- first failure witnesses.

## Interpretation

A source that passes gives an exact `1D -> 2D -> 3D` chain under one unchanged zero-guard role-stack recipe, for every first-step source transition in the declared width-three state space.

A source that only passes on some transitions has conditional rather than uniform recursive closure.

The evaluator contains no Wolfram class labels. The family is a mechanism control, not an unrestricted Class-IV test.

Because the successful 1D role-stack witness used only the rule block of `[r|s|delta]`, a recursive pass still does not by itself establish active derivative use. Role-band activation remains a separate criterion.
