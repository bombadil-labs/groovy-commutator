# Frozen next experiment: a guard-free axial dimensional family

Date: 2026-09-10. Status: planned, not executed. This follows extension-freedom, and tests one declared dimension-uniform constructor without reserved row roles. It is not a novelty or naturalness claim.

## Constructor and domain

For each homogeneous ECA word r, let F_(r,i) apply that same one-dimensional ECA along axis i of a binary Z^d lattice, independently on every parallel line. Define G_(r,1)=F_r and G_(r,d)=F_(r,d) composed with ... composed with F_(r,1), in that order. The last axis is applied last. The recursive native description is(r,d,ordered axes), retaining the original word explicitly.

This defines an ambient binary CA on every d-dimensional configuration, with Moore radius at most1 and no guards, boundaries, role tags or reserved program/data rows. The word r remains in the law; mutable spatial programs are not claimed. One macro update consists of d lattice passes. A naive single-output circuit evaluates1+3+...+3^(d-1) ECA lookups on a3^d-site input block. Report both costs rather than calling the processing constant.

The proposed literal embedding R_d copies an arbitrary d-dimensional field unchanged along the new axis. It supplies an invariant coordinate constraint, not additional guard rows. This replication code is a particular prepared subset; do not call it spontaneous organization or positive extra-axis information density.

## Frozen questions and checks

1. For all256 r, determine exact first-interface compatibility G_(r,2) R_1=R_1 G_(r,1). Reduce it to the local uniform-response function u_r(b)=f_r(b,b,b) and exhaust all source triples. Record every failing rule's first witness. Do not repair failures by changing codes, cadence or the law within this experiment.
2. Determine exact second-interface compatibility on every arbitrary2D source field, not only first-lift images. Use the full512 three-by-three source patches to compare G_(r,3) R_2 and R_2 G_(r,2), exploiting replication to avoid enumerating every27-bit ambient patch. Prove what continues at every further dimension; distinguish sufficient conditions from any exhaustive classification actually obtained.
3. On all256 times512 two-dimensional patches, compare horizontal-then-vertical with vertical-then-horizontal. Retain an exact axis-order disagreement truth table or deterministic certificate and first witness per rule. Test axis-permutation equivariance, not reflection symmetry unless separately stated. A commuting pair of axial operators supplies an all-dimension permutation argument; a failed2D test excludes that symmetry for this constructor only.
4. Independently audit composition using a shrinking-array evaluator with direct Boolean truth words, not the primary integer table pipeline. Recover identity204, constants0/255, and affine axial-commutation controls; classify all source words without Class-IV labels.
5. Physical lattice controls for the binary G family: every width4 1D source state, every2-by2 2D state, and every2-by2-by2 3D state for each r, one macro update. Independently compare the ordered lattice passes and direct local composite rule. These are finite controls; causal-window proofs establish the unrestricted claims. No state trace is a self-assembly test.

Commit implementation before execution; preserve this protocol and all failures. Save canonical JSON, exact rule lists and witnesses, and add CI reproduction. Related commuting-CA results are established literature; do not infer novelty from obtaining a clean classification.

## Decision

Compare what is gained by removing guard/role machinery with what is lost in compatibility, axis symmetry and programmability. If a family works, distinguish uniform recursion from a unique or intrinsically preferred extension. If it fails, preserve the failed constructor and freeze a proposed rescue separately. Minimum dimensional ancestry and skipped levels still require their own admissible-encoding contract.
