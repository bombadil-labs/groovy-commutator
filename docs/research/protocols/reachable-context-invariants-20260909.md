The congruence certificate is deliberately strong. It requires substitutivity under every algebraically allowed related context, even when a one-defect trajectory can never realize those contexts.

The next question is therefore:

> **Can permanent invisibility be certified by an invariant that tracks only contexts generated from a single hidden defect inside an otherwise diagonal background?**

This checkpoint tests the first two levels of a spatial-language hierarchy: generated pair-symbol closure and generated nearest-neighbor edge closure.

## Exact paired macro dynamics

Reuse the Research031–032 matched block-3 construction. Every ECA rule induces an exact radius-1 macro CA

\[
g:A^3\to A,
\qquad A=\{0,\ldots,7\}.
\]

The paired dynamics acts on

\[
B=A\times A
\]

by

\[
\widehat g((a,a'),(b,b'),(c,c'))
=
(g(a,b,c),g(a',b',c')).
\]

A paired symbol `(u,v)` is **target-visible** for binary target `T` when

\[
T(u)\ne T(v).
\]

Let

\[
D=\{(a,a):a\in A\}
\]

be the diagonal paired alphabet. For a hidden seed pair `s=(a,b)` with `T(a)=T(b)`, the admissible initial configurations are arbitrary diagonal backgrounds with exactly one occurrence of `s`.

This is exactly the causal-witness semantics used in Research031–032: a finite witness exists iff some admissible one-seed paired trajectory eventually contains a target-visible paired symbol.

## Level 1: least generated pair-symbol closure

For a fixed `(rule,T,s)`, initialize

\[
S_0=D\cup\{s\}.
\]

Iterate

\[
S_{n+1}
=
S_n\cup
\{\widehat g(x,y,z):x,y,z\in S_n\}
\]

until stable.

Call the fixed point `S_*`.

### Symbol-closure theorem

Every paired symbol that can occur in any admissible one-seed trajectory lies in `S_*`.

Proof: the initial row uses only `D union {s}`; if one row uses only `S_n`, every next-cell triple lies in `S_n^3`, hence every next symbol lies in `S_{n+1}`.

Therefore

\[
S_*\cap V_T=\varnothing
\Longrightarrow
w_T(a,b)=\infty,
\]

where `V_T` is the set of target-visible paired symbols.

This certificate is weaker than requiring `S_*` to be an equivalence relation or a target congruence. It tracks the subalgebra generated by the diagonal background plus the actual defect seed.

### Exact control against Research032 congruence

Every Research032 congruence-certified seed must also pass the generated-symbol certificate. If `R` is a target-safe congruence containing `D` and `s`, closure of `D union {s}` under `g_hat` remains inside `R`.

Thus the generated-symbol certificate must contain all 47,352 congruence-certified unresolved distinctions. Any miss is an implementation error.

Primary new measurement:

- number of the 5,360 non-congruence residual distinctions newly certified by `S_*`.

## Level 2: least generated nearest-neighbor edge closure

Symbol closure still permits every triple of generated paired symbols, including spatial juxtapositions that may never occur.

Track adjacency explicitly.

Let `E` be a directed graph on paired symbols. Its bi-infinite paths form a one-step shift of finite type.

For seed `s`, the exact initial one-defect language has adjacent pairs

\[
E_0=(D\times D)\cup(D\times\{s\})\cup(\{s\}\times D).
\]

Given an edge set `E_n`, every allowed length-4 path

\[
p_0\to p_1\to p_2\to p_3
\]

produces the adjacent output edge

\[
\widehat g(p_0,p_1,p_2)
\to
\widehat g(p_1,p_2,p_3).
\]

Define `E_{n+1}` by adjoining every such output edge and iterate to a fixed point `E_*`.

### Edge-language theorem

Every adjacent pair appearing in any admissible one-seed trajectory belongs to `E_*`.

Moreover, by construction every length-4 path admitted by the fixed-point edge shift maps to another allowed edge. Hence the edge shift generated by `E_*` is forward invariant under the paired CA.

Therefore, if no endpoint of any edge in `E_*` is target-visible,

\[
\boxed{w_T(a,b)=\infty.}
\]

This is a sufficient certificate. Failure is inconclusive because a one-step SFT can splice individually allowed edges into longer words that are not jointly reachable.

### Monotonic hierarchy control

Every seed certified by generated-symbol closure must also be certified by generated-edge closure. The edge language can only remove spurious spatial combinations relative to unrestricted symbol closure.

Primary new measurement:

- number of residual distinctions certified by edge closure;
- incremental gain over symbol closure;
- remaining unresolved family after edge closure.
