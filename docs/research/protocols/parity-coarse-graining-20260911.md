## 1. The transformation and its costs

`T_π` (neighbor-parity coarse-graining): `π(S)_i = S_i ⊕ S_{i+1}`, the map of elementary rule 102 applied once as an observation, on a ring of `n` cells.

| component | transport or cost |
| --- | --- |
| alphabet | `{0,1}` → `{0,1}`; `π` is XOR-linear |
| fibers | exactly `{S, ¬S}` on every ring (`ker π = {0ⁿ, 1ⁿ}`); two-to-one |
| image | the even-parity configurations, `2^{n−1}` states; on the line, `π` is onto |
| forward locality | radius 1 (asymmetric window `{i, i+1}`) |
| inverse | none as a map; any right-inverse needs one global anchor bit and is non-local (prefix parity) |
| information | one bit per ring, global, not per site |
| law | none transported a priori; a factor `B` with `π ∘ F = B ∘ π` exists only for closed rules (Section 2) |
| derivative, commutator | `D_r = 𝟙 ⊕ F_r`; where `B` exists, `D_B = 𝟙 ⊕ B` and `G_B` are computed natively on the parity field |

This is the observation-closure setting of Research022 with the observation fixed to `π` for every rule, rather than the per-rule derivative observation `D_r`. The complement response `g_r(l,m,r) = r(l,m,r) ⊕ r(¬l,¬m,¬r)` of the [first audit](representation-invariants-audit-20260910.md) reappears here: `π` identifies exactly the complement pairs, so closure under `π` is a statement about `g_r`.

Definitions used unchanged: factor closure means a deterministic `B` on the image with `π ∘ F_r = B ∘ π` (Research022, shared closure account); `R_0` identifies `S` with `¬S`, `R_{t+1} = R_t ∩ F_r^{−1}(R_t)`, and `h_*` is the least `h` such that the observed word `(Y_0, …, Y_h)` determines `Y_{h+1}` for every microstate (Research023). Because every `R_0` class has exactly two members, `h_*` equals the largest first time `t ≥ 1` at which some pair `(F_r^t S, F_r^t ¬S)` leaves `{equal, complementary}`, and is `0` exactly when no pair ever does.

## 2. Frozen predictions

- **C1 (closure classification).** For every `n ∈ {6, 8, 10, 12}`, the set of rules with factor closure under `π` is exactly the 32 rules whose complement response `g_r` is constant: the 16 complement-invariant rules `{0, 24, 36, 60, 66, 90, 102, 126, 129, 153, 165, 189, 195, 219, 231, 255}` (`g_r ≡ 0`) and the 16 self-dual rules `{15, 23, 43, 51, 77, 85, 105, 113, 142, 150, 170, 178, 204, 212, 232, 240}` (`g_r ≡ 1`). Reason: `π F(S) = π F(¬S)` iff `F(S) ⊕ F(¬S) ∈ {0ⁿ, 1ⁿ}`; a non-constant `g_r` places two neighborhoods with different responses on one ring once `n ≥ 6`. Rings `n = 4, 5` are reported without prediction (finite-size admissions allowed there, as with invertibility in `secondorder.py`).
- **C2 (the factor is elementary).** For each of the 32 closed rules the factor `B` is an elementary rule on the parity field, given exactly by: write `r(l,m,r) = q(l⊕m, m⊕r)` (complement-invariant) or `r(l,m,r) = m ⊕ q(l⊕m, m⊕r)` (self-dual) for a Boolean `q` on two inputs; then `B(y)_i = q(y_{i−1}, y_i) ⊕ q(y_i, y_{i+1})`, respectively `y_i ⊕ q(y_{i−1}, y_i) ⊕ q(y_i, y_{i+1})`. The verifier extracts `B` by brute force on the `n = 8` image (well-definedness on fibers, then radius-1 consistency across all sites and states) and compares the extracted table with the formula for all 32 rules. Specific frozen values: rule 90 maps to rule 90 (the known dyadic-parity fixed point of Rule 90; [history repairability](../2026-09-07-history-repairability.md)); the 16 affine rules, all of which lie in the 32, map to linear factors, because `π` is linear and kills every constant vector; the 16 nonlinear closed rules map to nonlinear factors, because a quadratic term in `q` survives the XOR of two shifted copies. The full map `r ↦ B(r)` and its fixed points are reported, not predicted.
- **C3 (commutator covariance, theorem control).** For the 32 closed rules, `π ∘ G_r = G_B ∘ π` on all `2^n` states for `n ∈ {8, 10}`, where `G_B` is the native commutator of `B`. Proof: `π` is linear, so `π D_r = π ⊕ π F_r = π ⊕ B π = D_B π`, hence `π G_r = π (D_r F_r ⊕ F_r D_r) = D_B B π ⊕ B D_B π = G_B π`. The run is a control. Consequence, also frozen: the 8 one-G rules `{15, 51, 85, 105, 153, 165, 195, 255}` (all closed, all affine) have factors with `G_B ≡ 0` on every configuration, since a linear factor has zero commutator by established result 1; the 16 nonlinear closed rules have factors whose `G_B` varies with state, since a nonlinear factor with only linear and quadratic terms is never rule 4 or 200, the sole nonlinear zero-G rules. The result-1 class of `B(r)` is tabulated for all 32.
- **C4 (refinement for the non-closed rules).** For all 256 rules and `n ∈ {6, 8, 10, 12}`, compute `h_*` and the number of `R_0` classes that `R_∞` splits, by iterating every complementary pair until it separates or until `2^{n+1}` steps have passed without separation (the pair orbit lives in a space of `2^{n+1}` states, so an unsplit pair after that many steps is periodic and never splits). Frozen: `h_* = 0` exactly on the C1 set at every `n` (the shared closure account's identity "factor closure iff `R_0 = R_∞`"). No prediction on the magnitude or `n`-dependence of `h_*` or of the split fraction for the 224 non-closed rules; both are reported per rule and per `n`, together with whether `h_*` is non-decreasing in `n` for each rule.
- **C5 (relation to the first audit, deduction).** The closed set equals the union of the complement-covariant rules of the first audit (native commutator covariant under `T_c`, the 16 self-dual rules) and the 16 complement-invariant rules. The verifier reads the first audit's saved self-dual set from `results/representation_invariants_20260910.json` and checks the set identity.

## 4. Not claimed

Nothing about other coarse-grainings (block majority, 2-block projection, any non-linear `π`), about `k`-cell parities with `k > 2`, about the infinite line beyond what the finite identities imply, or about locality of `R_∞` itself for the non-closed rules; Research023 already shows that `h_*` can grow with `n`. No Class IV, novelty, or renormalization claim: exact parity coarse-graining of Rule 90 is a textbook fact and is used here only as a frozen control value. C3 is a theorem; its run is a control, and the note will say so.

## 5. Protocol review record (2026-09-11, before implementation)

Codex reviewed revision `9997462` and confirmed the C1 threshold argument, the C2 factor formula and extraction (every three-bit parity-field neighborhood occurs in an even-parity `n = 8` state, so the extraction determines a unique elementary extension), the C3 intertwining proof (the parity image is an XOR subspace preserved by `B` and `D_B`; the all-configuration claims about `G_B` use the explicit elementary extension and established result 1, not surjectivity), the `h_*` restatement (an `R_0` pair survives `R_h` exactly until its first observed separation; equality `R_h = R_{h+1}` is absorbing), and the C4 termination bound as a count over unsplit ordered pairs (`2^n` equal plus `2^n` complementary), not the product space. Non-blocking clarifications, binding on the implementation and the note:

1. Cadence is `q = 1`. Count each initial complement pair once (fix one source bit) and use `2^{n−1}` as the split-fraction denominator. Record first separation times with the convention that a pair separating first at time `t ≥ 1` contributes `h_* ≥ t`. "Never separates" is asserted only by the termination proof (equality is absorbing; stop at equality), never by an arbitrary runtime cutoff. Memoization or exact cycle detection may be used without changing the domain or predictions.
2. A right-inverse of `π` can fix an anchor (for example `S_0 = 0`) rather than receive a bit; recovering the original fiber member requires the missing anchor bit; both are non-local. "One bit lost" means `log₂` of the fiber size, equivalently the conditional entropy under a uniform prior, not an entropy statement for every prior.
3. This is overlapping neighbor parity at the original lattice spacing and cadence one, distinct from the non-overlapping dyadic-parity, cadence-two coarse-graining cited as context in the history-repairability note. Rule 90 being fixed here follows from commuting linear maps; the two contracts stay distinct.

Codex's reading of the unit: the new empirical content is C4's timing and fraction of complement distinctions that become observable; C1–C3 and C5 calibrate the construction against available algebra. Material changes to domain, predictions, budgets or scoring require renewed review.
