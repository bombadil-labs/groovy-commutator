# Frozen protocol: same phases, different training histories

Issue #333. This freeze precedes implementation and any held-out spacing evaluation. Prior orientation counts in the shared conversation are exploratory targets, not acceptance thresholds.

## Decision and source
We ask whether learned bond placement predicts a phase-only distinction after an exactly matched phase reset, above two directional means and above the per-axis distributions alone. If the placement contrast is absent, stop this unit rather than broadening the search. A null is about the chosen readout and times, not all downstream observers.

## Design
- 16×16 periodic square grid; update synchronous phases first, then adapt bonds using the new phases. Euler dt=.04, eta=.5, r=5.9, nonnegative bonds, R0=I1/I0 evaluated by convergent power series instead of the original approximation. Round stored phases, frequencies, and bonds to Float32 as in the tour. One run uses a deterministic replay; no per-step noise, rendering, or integrator history.
- 32 independent pairs, IDs 1–32, deterministic PCG64 streams keyed by (333, pair ID, stream ID). Use streams 0 (initialization), 1 (reset), 2 (axis shuffles), and 3 (global shuffle). Within pair share initial iid uniform phases on [0,2π), iid uniform bonds on [.1,.3), reset phases (a fresh independent draw from the same phase distribution), and shuffle permutations. Per-axis permutations independent of each other. Do not tune using pairs 1–32. Fixtures use analytic states or distinct pair ID 0.
- Train for exactly 3000 ticks with frequencies .8+.9 sin(2πkx/16). Main histories k=1 vs k=3, both along x. These are distinct sampled modes and their sampled frequencies have the same multiset, because multiplication by 3 permutes the 16 residues. Construct one sampled sine table and reuse it by permutation; no duty-cycle or frequency-distribution difference. The neighboring gradients intentionally differ. Orientation control: k=1 x vs k=1 y. Use the same seed set for calibration, report it separately.
- At tick zero of readout replace both phases by the same exact array, set every consumed natural frequency to Float32(.8), and apply one intervention to bonds: intact, within-axis uniform independent permutation, separate uniform per-axis means, shared untrained initialization, or global permutation (orientation baseline only). Every readout, including ablations, then follows the same live learning update. This tests which *initial* summaries suffice, not which variables can be removed throughout evolution.
- Compare matched shared untrained resets bitwise on raw phase trajectories at all ticks to 2500, for each history pair; assert byte-equal phase/frequency state at reset in all arms. Assert equality of sorted per-axis bonds after within-axis shuffling and global sorted bonds after global shuffle. Failure is a control/implementation failure, not a null.

## Readout and uncertainty
Take ticks 250/1000/2500 and make 1000 primary. Let c(x) be the y-average of cos(θ(x+1,y)−θ(x,y)), using only visible phases. Let P_j be the sum of normalized squared Fourier amplitudes at ±j of c. Score S=P6−P2. The doubled frequencies are motivated by the even cosine of the derivative of a sinusoidal phase pattern. This score is translation- and global-phase invariant, and measures spatial modulation of local alignment, not literal restoration of the driven phase or any chosen relative cluster offset. Verify constant, analytic sinusoidal phases with amplitude 0.6 at k=1/3 (desired score signs negative/positive), axis rotation and translation/global-phase invariance before evaluation. Note an axis-rotated ideal stripe is blank for this x-edge readout.
- Main estimate: across-pair mean of Δ=S(k3)−S(k1); pair concordance is fraction Δ>0 with ties worth half, not independent single-trial accuracy. Report each arm, both history mean scores, and paired Δ differences of intact vs shuffle and intact vs means. Bootstrap 10,000 paired resamples at 95% percentile, PCG64 seed 3331000+readout tick, sharing index draws across arms for a tick. Treat other horizons as sensitivity, not additional success gates.
- Call placement supported under this readout if at t=1000 the descriptive intervals for intact Δ and intact-minus-each placement-destroying arm all lie above zero with valid matched baseline and orientation calibration; otherwise do not claim the placement result. These intervals are not simultaneous intervals or causal estimates beyond the selected initial-state intervention.
- Secondary check: direct unit-complex phase power at ±3 minus that at ±1, averaging y before taking x powers. Report Δ descriptively, not an alternate success gate.
- Orientation positive control: score mean vertical edge cos minus mean horizontal edge cos, positive predicts x-history; report paired contrast and fixed zero-threshold balanced accuracy (half ties). Require intact calibration mean paired contrast >0 with its interval above zero at the primary horizon. Include global shuffle separately, not as substitute for the within-axis control.

## Boundary and stop
Equal-visible states here are imposed by intervention, not asserted naturally reachable. A difference identifies information retained by this temporal dynamics and readout, not persistence indefinitely, unique encoding, Class IV, or evidence for lattice physics. Optional Groovy transfer only if an existing endogenous rule-field model provides a comparably well-defined, documented state split and phase-only readout under the bounded unit. If not, document the obstacle; no new model, parameter sweep, or automatic follow-on.
