## Question

Can the dimensional program distinguish translation directions **available to a declared state family** from displacement directions **actually used by a local law**, without turning either quantity into an intrinsic definition of dimension?

The user's phrase “dependent origination” motivated this question. It is not evidence, a Buddhist-doctrinal claim, or a physical hypothesis in this experiment.

## Answer

Yes as a bookkeeping distinction, with an important negative result.

For a declared state family `B`, the protocol defines translation rank

`rho_T(B) = rank_Q((H_B / K_B) tensor Q)`,

where `H_B` is its setwise lattice-translation group and `K_B` is the subgroup that fixes every member pointwise. For a local CA rule `g`, causal displacement rank

`rho_C(g) = rank_Z <E(g)>`

is generated by the essential nonzero input offsets.

These quantities successfully separate several known confounds. A literal copied 1D family inside a 2D target keeps `rho_T=1` even though the ambient target has rank 2; finite product alphabets and arbitrarily many anchored channels likewise need not raise `rho_T`. But `rho_T` is explicitly presentation-relative: taking the translation closure of the anchored channel family raises it from 1 to 2.

For the accepted ordered-axis ECA constructor, the new causal-rank census adds **no new rule classification**. The frozen product theorem is exact:

`E(G_{r,2}) = E_r × E_r`.

The complete `256 × 512` local replay agrees with that theorem with no discrepancy. Target `rho_C` is therefore determined entirely by the source rule's essential-offset set.

All frozen P1–P8 verdicts pass. The result is useful as a separation of resources and a negative-information result; it is not an intrinsic-dimensional invariant.

## Definitions and frozen controls

### Translation rank `rho_T`

For a family `B subset A^(Z^D)`:

- `H_B = {v in Z^D : tau_v(B)=B}`;
- `K_B = {v in H_B : tau_v(x)=x for every x in B}`;
- `rho_T(B)` is the free rank of `H_B/K_B`.

The exact controls are:

- binary 0D state set: `rho_T=0`;
- full 1D shift: `rho_T=1`;
- full 2D shift: `rho_T=2`;
- literal 1D→2D copied image: source rank 1, copied-image rank 1, full target rank 2;
- any finite product alphabet over the same `Z` lattice: rank 1;
- anchored finite `m`-track family: rank 1;
- translation closure of that same anchored-track family: rank 2.

The last pair is deliberate. It shows that `rho_T` changes when the declared family/presentation changes; the protocol does not hide that dependence.

### Causal displacement rank `rho_C`

For a translation-equivariant local rule, an offset is essential when flipping only that input can change the output. `rho_C` is the integer rank generated by all essential displacement vectors relative to the output origin.

The center offset contributes no rank. Thus constants, identity and center-negation have rank 0; a one-cell shift has rank 1; essential non-collinear offsets span rank 2.

This is a local law-use measure. It is not the dimension of the ambient lattice and is not claimed invariant under arbitrary recodings.

## Exact ordered-axis result

The accepted two-axis constructor applies the same ECA rule first along `x` and then along `y`. If `E_r subset {-1,0,+1}` is the set of essential 1D offsets of source rule `r`, the protocol's Gate-1 correction proved

`E(G_{r,2}) = E_r × E_r`.

The verifier independently evaluates all 512 Moore patches for all 256 rules using two local implementations and then recomputes essential offsets. The complete replay has:

- zero product-theorem discrepancies;
- identical primary/reference target hashes;
- source `rho_C=0` exactly for `{0,51,204,255}`;
- target `rho_C=0` exactly for `{0,51,204,255}`;
- target `rho_C=1` exactly for `{15,85,170,240}`;
- target `rho_C=2` for the remaining 248 rules;
- transition counts `0→0: 4`, `1→1: 4`, `1→2: 248`, and no `1→0` collapse.

The explicit analytic controls also pass: rules 170/85 reduce to the southeast diagonal dependency, 240/15 to the northwest diagonal dependency, rule 90 to four-corner parity, and rule 150 to nine-site parity. Rule 51 correctly reduces to the center after two NOT passes.

The important conclusion is negative: **inside this constructor, target causal rank is already fixed by source essentiality.** The `rho_C` census is a theorem regression, not an independently selective dimensional classifier.

## Relational-lift profiles

The protocol keeps the profile

`(rho_T(source family), rho_T(inherited image), rho_T(target family), rho_C(target law))`

only as bookkeeping.

The 0D→1D center-only case is `(0,0,1,0)`: one target translation direction becomes available, while the inherited unary law uses no nonzero displacement.

The copied 1D→2D axial case is `(1,1,2,rho_C(G_{r,2}))`: the full target makes a second translation direction available, the copied inherited family still has rank one, and the local law may use causal rank 0, 1 or 2 according to the theorem above.

This terminology must not be shortened to “the system is dimension `rho_C`.” Identity dynamics on a 2D lattice remain dynamics on a 2D lattice even though their causal displacement rank is zero.

## What this changes

This result sharpens a recurring distinction in the dimensional program:

- ambient coordinate count;
- number of stored per-site coordinates;
- number of independently addressable channels/actions;
- translation rank of a declared state family;
- causal displacement rank of a local law

are different resources.

The new ranks are useful because they reject several obvious false identifications. They are also deliberately modest: `rho_T` visibly depends on the family/presentation, and for the accepted ordered-axis constructor `rho_C` turns out to be a deterministic restatement of source essentiality rather than a new selector.

That negative-information result is part of the outcome, not a failure to be rescued after the fact.
