# Neighbor-parity coarse-graining closes exactly on the constant-complement-response rules

The observation `π(S)_i = S_i ⊕ S_{i+1}` (rule 102 applied once, cadence one) identifies each state with its complement and nothing else. Its factor closure holds for exactly 32 elementary rules at every ring size `n ∈ {4, 5, 6, 8, 10, 12}`: the 16 complement-invariant rules and the 16 self-dual rules, the rules whose complement response `r ⊕ r∘¬` is constant. Each closed rule has an elementary factor on the parity field, `B(y)_i = q(y_{i−1}, y_i) ⊕ q(y_i, y_{i+1})` with `y_i` added for self-dual rules; the factor map is two-to-one, pairing each rule with its complement-conjugate, its fixed points are the 8 linear rules, affine rules map to linear factors and nonlinear closed rules to degree-2 factors. The commutator is covariant, `π ∘ G_r = G_B ∘ π`, by linearity of `π`, so the one-G rules map to zero-commutator factors. For the 224 non-closed rules the refinement depth `h_*` of the Erased Distinctions chain is 1 for 216 rules and 2 for `{22, 73, 104, 109, 146, 151, 182, 233}`, unchanged across the tested rings; that bound is post hoc, not predicted. See the [parity coarse-graining note](../research/2026-09-11-parity-coarse-graining.md). Scope: one coarse-graining, rings up to 12.
