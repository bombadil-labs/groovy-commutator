# Lifted rule measurements relate to classes without a clean classifier

Status: exploratory, finite-family census with a failed preregistered improvement prediction.

All 256 ECAs have faithful sequential native lifts through 4D on every width-seven and width-eight source word under the frozen four-field recipe policy. Each parent is completed once before its child. Exact physical partial rules and decoders are preserved. The [research note](../research/2026-09-14-on-beam-256-4d-classes.md) contains the methods, archive availability and review provenance.

Class IV has the highest all-recipe mean source-coordinate algebraic degree and high phase rank; Class III also has high rank but its mean degree lies below Class II. Forced-key counts can agree across I, III and IV. These quantities are measured in the source coordinates of the encoding, not as minimum native-rule circuit complexity.

A frozen orbit-held-out classifier reaches 55.35%/56.86% balanced accuracy from 2D–4D features alone. Adding those features to source and recipe baselines reduces accuracy by 2.155 points at both widths; the preregistered improvement criterion fails. Four published Class IV symmetry orbits, overlapping class distributions and recipe dependence limit interpretation.

This supports studying degree and rank jointly as descriptive signatures. It does not establish a class boundary, new information beyond C, arbitrary-input lifting, recursive G, or dimension induction. A new compact-rule invariant would need a separate test.
