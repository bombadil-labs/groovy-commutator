# History repair depends on the observation

## Current claim

At width 420, Rule 30 derivative prediction improves from mean error 0.2500 to 0.0011 between depths zero and six. Parity block size two changes from 0.3750 to 0.3855; block size four changes from 0.4676 to 0.4871.

These are different views of the same underlying rule. High history repair alone therefore cannot distinguish Rule 110 from Rule 30, the Class III comparison rule.

## Scope and limits

The estimator, sampling stride, block size, context coverage, and finite data all matter. In particular, unsupported full histories use shorter contexts. These scores describe the tested prediction procedures, not an intrinsic scalar complexity of a rule.
