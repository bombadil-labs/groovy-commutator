# Rule ambiguity can exceed future ambiguity

After six observed transitions on the eight-cell ring, 10,430 of 42,718 distinct panels admit multiple rules, but only 96 have multiple next-four-row continuations. The full finite experiment covers all elementary rules and all initial states at widths 6/8/10. Rule-identifier bits and purpose-specific future-code bits are different budgets.

See [the provenance experiment](../research/2026-09-08-spacetime-provenance.md) for definitions, exact bounds, data, and limits.
