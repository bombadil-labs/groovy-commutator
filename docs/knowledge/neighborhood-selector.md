# Eight neighbors can supply their center’s rule

The surrounding eight cells supply the rule outputs; a horizontal or vertical triple including the center supplies the address. Every output copies one surrounding bit. Uniform zero and one are fixed, but total population is not conserved.

Enumeration and an independent polynomial argument give exactly six quartic terms, all nine inputs essential, and 36,000 distinct functions per axis. This is an all-local-input result. The reported global cycles concern only 3×3 and 4×4 periodic grids. The factorization into a same-time rule table expands to a fixed local rule; that does not invalidate its instructional interpretation.
