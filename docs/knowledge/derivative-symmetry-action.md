# States and their changes transform differently

For the dimensional interpreter, D(HX)=JD(X), while G(HX) XOR JG(X)=F(JD(X)) XOR JF(D(X)). The latter is nonzero on 504 of 512 states of the tested 3×3 periodic system. The algebra is general for this symmetry; the count is finite.

Retaining the base state gives T_X(delta)=F(X) XOR F(X XOR delta), which respects the change symmetry. T_X(D(X))=D(F(X)) for every binary update map by construction; this identity cannot select Class IV by itself. It uses present context, without requiring a recorded history.
