# A held site can restore one published Rule-54 route

On the 34-cell ring formed by combining published Rule-54 ether and glider
junction words, all 34 rotations with all 34 one-bit injuries define 1,156
trials. A single addressed choice between Rule 54 and the identity rule
at time two, followed by Rule 54 to time eight, has 408 successful trials
with full-state knowledge versus 340 passively or with the best fixed
address. All 68 added successes first return to the undamaged route at
time seven. The result is an exact finite full-state feasibility gate.

If the original injury address is supplied by an external oracle, simply
holding that site achieves the same 408 successes. No G observer, local
coordination mechanism, controller cost advantage, repeated disturbance
or infinite-line glider persistence follows. The source paper motivates
the seed; the finite ring and exact-route task are our adaptation.
