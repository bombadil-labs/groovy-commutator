# Affine evolution has a constant commutator

## Statement

For \(E(S)=MS\oplus c\), with \(M\) linear over binary arithmetic and \(c\) a fixed bias, define \(D(S)=S\oplus E(S)\). Then

\[
G(S)=D(E(S))\oplus E(D(S))=c.
\]

The linked research note gives the cancellation explicitly. This implication does not depend on one spatial dimension. It is sufficient for a constant commutator, and does not assert the converse.
