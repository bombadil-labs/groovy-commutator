# The tested Rule-90 defects do not recover within four ticks

All six-cell XOR masks and all 512 causal backgrounds were checked, with
periodic and isolated physical application. At fine ticks two and four, none
of the initially invalid cases is back in the stationary Rule-90 encoding:
31,744 periodic cases and 32,256 isolated cases remain outside. The periodically
repeated matched logical flip starts valid and stays valid instead.

The finite causal windows include every potentially changed block, so the
result covers arbitrary infinite extensions of each enumerated background.
It is a four-tick result, not a claim of permanent damage. Odd-tick shifted
representations were not classified.

For isolated defects, locally valid blocks need not agree with their remote
vertical copies. At any finite time, genuine global recovery to this repeated
code must equal undamaged evolution, because those untouched copies fix the
logical content. This restriction belongs to this code architecture.
See [proof, measurements, and audit](../research/2026-09-08-encoded-defects.md).
