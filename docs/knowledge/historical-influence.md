# Historical influence in the dynamics

A past difference has causal influence when changing what is retained from
it changes later behavior under a specified intervention. The retained
quantity belongs to the system's evolving state: for example, a persistent
rule field or the additional state in second-order dynamics.

This differs from giving a predictor more observations of an unchanged
trajectory. In a deterministic Markov description, the complete present
state carries everything the dynamics uses. If identical alleged complete
states have different successors under identical conditions, the state
description or the model assumptions need revision.

The [wider program](../research/2026-09-07-history-and-possibility.md) keeps
these objects separate. Its proposed selective-retention tests require causal
interventions and recovered source artifacts before earlier reported results
can be treated as verified. Retaining more history need not be useful.
