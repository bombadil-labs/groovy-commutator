# The finite-cone defect experiment is complete

The frozen experiment applies all 64 six-cell XOR masks to the Rule-90 code,
both repeated vertically and confined to one block, on all 512 causal logical
backgrounds. It samples fine times zero, two, and four, separating local codeword
validity, global encoding validity, content recovery, background dependence,
and failure of XOR superposition for all 15 pairs of single-cell flips.

An independently written Boolean truth-set implementation agrees on all
196,608 sampled response fields, 384 aggregate records, all per-background
classifications, and 90 pair records. Shrinking windows remove artificial
boundary conditions. The complete result and its four-tick bounds are in the
[research note](../research/2026-09-08-encoded-defects.md).
