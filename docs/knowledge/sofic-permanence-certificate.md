# An orbit-inclusion certificate is what would prove an erased distinction permanently irrelevant

A finite horizon of silence is not a permanence proof. If an attached
distinction has not become visible through macro-horizon `t`, nothing about
`t+1` follows. The program's sharpest structural result says what a proof
object would have to look like instead.

For the paired one-defect source language of the matched block-3 / cadence-3
ECA observer, with `X_t` the exact time-`t` sliding-block image of the source
set and `U_t = union_{j<=t} X_j`, an inclusion

```
X_{t+1} subseteq U_t
```

together with target safety on the finite prefix certifies that the erased
distinction is **never** visible, at any later time. The ingredients are that
the paired one-defect source language is sofic and that sliding-block images
of sofic shifts remain sofic, so the inclusion is a decidable question about
finite presentations rather than an infinite check. When the inclusion fails,
an exact target-visible label supplies a finite counter-witness.

## Scope and limits

The theorem is about *what would prove permanence*, not about how expensive
that proof is to build. On the declared 170-question frontier the certificate
has never been supplied: no same-source temporal-recurrence certificate exists
through `h <= 6`, and the direct exact sofic construction exceeded its frozen
explicit-graph budget. The construction is stated for this observer, this
cadence, and this one-defect source family; it is not a claim about arbitrary
cellular automata or arbitrary coarse-grainings. Failure to find a certificate
under any particular proof grammar is a statement about that grammar, not a
proof that the distinction does return.

What would change the account: an exact certificate on any frontier question,
or a structural theorem bounding the presentation size the certificate needs.
