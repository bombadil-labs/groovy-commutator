# Correction stacks and observed futures retain the same distinctions

For a deterministic binary evolution F and a same-type observation A, let
A_0=A and A_(k+1)=A_k F XOR F A_k. The whole-field tuples
(A_0,...,A_h) and (A,AF,...,AF^h) are related by an invertible triangular
transformation. They identify exactly the same microstate pairs.

This is an algebraic result for every finite h; the
[research note](../research/2026-09-09-correction-future-coordinates.md)
contains the proof, exhaustive audits, and limits.

A finite tuple closes when the next correction is determined by that joint
tuple. Individual correction maps need not repeat. The infinite-stack update
U'_k=F(U_k) XOR U_(k+1) is local, but supplying infinitely many prepared layers
is a different resource from a finite locally prepared representation.

The coordinate transformation can enlarge spatial neighborhoods. Forward
observations are not past data available at the same instant. Neither this
theorem nor the infinite-stack control establishes that the source program
has become active spatial data under a recursively closed dimensional grammar.
