# A shared space for states and rules

An elementary rule, an eight-cell binary ring, and an eight-neighbor pattern each contain eight bits. A declared permutation maps physical positions to rule-table addresses. Closure follows from this encoding; it does not supply every possible transformation or a unique decoder.

The completed experiment compares frozen, mutual, and derivative rule updates, plus a two-dimensional neighborhood selector. The complete update law remains fixed in each case. See [the shared-space research note](../research/2026-09-08-shared-state-rule.md).
