# Can recursive program lifts use finitely thick prepared boundaries?

The [editable-routing construction](../research/2026-09-09-editable-routing-tables.md) gives exact execution, local instruction edits, and autonomous program transport, but supplies infinite guard half-spaces at each lift.

A next bounded experiment should replace those half-spaces with an explicit finite-thickness arrangement. Specify the boundary symbols and update rule, the allowed new-dimensional source fields, a local decoder, and the cost of one inherited edit. Then prove stability and execution before a frozen finite audit.

A boundary that remains fixed because required inputs are missing must be recorded as an architectural mechanism. Removing an infinite guard preparation would not by itself establish spontaneous layout formation or eliminate protected role tags.

This is an open resource question. The existing result does not prove finite-thickness closure or a minimum boundary width.
