# Observation signatures need an explicit source ensemble

The [first observation catalog](../research/2026-09-15-observation-catalog.md)
enumerates 24 primitive views and all 276 pairs under one comparison contract.
It retains event partitions and source transition maps, not only scalar scores.
Exact local redundancy leaves 44 to 284 distinct partitions per ECA.

Seven mechanically chosen measurement/observation intervals preserve the full
54/110 symmetry families when exhaustive source rings grow from widths 7/8 to
9. None preserves both canonical roots at both tested developed-trajectory
seeds. This is a bounded failure of those frozen scalar intervals. It does not
show that all catalog observations, or their complete partition structures,
fail to distinguish dynamical roles.

The developed comparison changes width, ensemble and sampling together. A
future factorial comparison should separate them; the current result does not
attribute the failure solely to ensemble choice. Observation, ensemble and
causal/temporal support are explicit parts of the measurement contract.

Native view matching is separately scoped to six newest-axis phases with older
coordinates zero. Constant partitions and inherited copies count as matches,
so match counts are not class evidence. The full data support inspecting shape
and relational organization in later work without selecting another favored
observable prematurely.

## Ring arithmetic extension, 2026-09-15

The [whole-state partition study](../research/2026-09-15-rule-ring-structure.md)
keeps the source ensemble fixed while comparing rule relations across rings.
Its extensible instrument retains arithmetic descriptors, full partitions and
comparison provenance. The strongest first-order discovery associations mostly
reverse sign in the small held-out range. This narrows that selected correlation
claim; it does not reject conditional arithmetic structure or establish class
specificity. Raw source width, arithmetic support and whole-state observations
remain separate coordinates of the comparison.
