# Retaining the interface repairs only the first update

The six-bit encoding W keeps all four touching cells and both outer variable
cells of the adjacent strips. It contains every original two-tick output,
but is not invariant at cadence two: only 69,264 of 262,144 unrestricted
local symbol triples preserve it.

This is not only failure on unreachable symbol combinations. Among all 1,024
original causal inputs at fine tick four, 399 leave W and 183 change a cell
outside the original four rows. Independent implementations agree on the
entire declared census through tick eight.

The result excludes this encoding as an exact recurrent joint description.
It does not exclude every possible compact description. See the
[encoding and reachable-state comparison](../research/2026-09-08-interface-state.md).
