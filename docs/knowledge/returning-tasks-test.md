# Compare returning tasks and revision policies

**Completed, 2026-09-07.** After an inherited construction serves eight old
tasks, changed and old tasks alternate for one, two, or four cycles. The
[experiment](../research/2026-09-07-returning-tasks.md) compares fixed,
replacement, and revisable libraries using the all-width program kernels.

Full-hindsight dynamic programming is compared with reactive current-block
optimization under two explicit tie rules. The oracle has more future
information; the reactive policy does not learn the repeating schedule.

There are 294,912 configurations and 4,212 aggregate rows. Direct enumeration
of 4,194,304 two-block paths agrees with dynamic programming, and selected
witnesses replay their complete costs. Learning, discovery, search costs,
and organizational survival remain outside this model.
