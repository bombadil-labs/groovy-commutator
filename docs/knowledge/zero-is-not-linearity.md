# Zero commutator is not a linearity test

## Inference

A test that returns the same outcome for an affine rule and a nonlinear rule cannot distinguish those possibilities on its own. Rules 4 and 200 provide exact nonlinear counterexamples to inference from zero self-commutator to affine evolution.

## What remains useful

The commutator still asks whether the outgoing change mask can be evolved under the same rule as the state. Its vanishing reports that compatibility. To check affine structure, inspect the rule’s Boolean expression or lookup table directly.
