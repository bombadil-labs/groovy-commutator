# One physical process has several exact effective laws

For the same six-cell encoding and fixed physical interpreter,

$$
FE=T_{0,-1}E\phi_{60}=T_{0,1}E\phi_{102},\qquad F^2E=E\phi_{90}.
$$

A frame moving left one physical cell per tick reads Rule 60; a frame moving
right reads Rule 102; stationary sampling every two ticks reads Rule 90.
These are fixed observation maps for every input. They do not modify the
physical trajectory or fit a decoder to a particular history.

This is dependence on declared coordinates and cadence, distinct from the
earlier case of different unknown rules producing one observed spacetime
panel. Effective-rule comparisons should carry encoding, frame, cadence,
and action map as provenance. The three descriptions are linked by exact
translation and XOR identities, not three independent discoveries of unrelated
behavior. See the [construction and proof](../research/2026-09-08-block-compatibility.md).
