# Finite width can be packed; independent unbounded width eventually defeats a fixed capacity budget

**Status: exact representation theorem with a bounded Rule32 diagnostic.** The [frozen protocol](../research/protocols/transverse-freedom-20260911.md) and [result note](../research/2026-09-11-transverse-freedom.md) distinguish nominal row count from independently growing transverse state capacity.

Every fixed finite-width strip can be column-packed into a one-dimensional CA over a width-dependent product alphabet. Conversely, an unconstrained width-`w` strip cannot inject for all widths into one fixed `q`-symbol target with fixed longitudinal expansion `K`, because `|A|^(wn) <= q^(Kn)` eventually fails. This non-packability verdict is a resource condition, not a definition of dimension.

For the inherited Rule32 correction family, every finite-depth tuple is a deterministic image of the same binary source family and therefore carries at most one bit of independent-state capacity per longitudinal site. In the bounded `n=6..12`, `h=0..4` diagnostic, every K/O and H128/H160 tuple partition is already saturated at `h=0`: deeper correction rows add no new whole-field distinctions on those tested finite families.

Scope: the source-bound claim is analytic for every finite correction depth. The observed saturation is only for the declared rings and depths. No intrinsic spatial-dimension theorem follows.
