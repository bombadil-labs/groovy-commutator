# Repeated changes can repay a retained construction record

The cost model charges the editable trace once while management costs recur.
With dispatch price one, trace reserve four, and four jobs per block, revision
with hindsight beats replacement with hindsight in 430 of 1,056 farther
literal changes for one return cycle and 893 for four cycles. The mean
saving changes from -0.691 to +8.599 units in that group.

The [sequence experiment](../research/2026-09-07-returning-tasks.md) preserves
the parent price schedule. Each cycle offers two management opportunities;
the conservative gain bound becomes ten times the number of cycles minus
the trace reserve. This is amortization under specified prices and known
tasks, not proof of a universal benefit from storing history.
