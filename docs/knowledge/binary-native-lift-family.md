# A small binary reference family realizes every ECA through 3D

Status: retrospective finding, independently replicated from scratch. Gate 2 accepted 2026-09-14 (Claude/Fable, exact head a641df751bc81b50947b8ea7bd1c4d9d2ae8203f, PR #233).

The P/D/M/Q grammar, with four reference formulas, four transition masks, two signs and six cyclic row orders, supplies a faithful first floor for all 256 ECA source rules. One reflection-aligned selection per rule repeats into 3D with uniform binary radius-two native evolution and local source/parent recovery. The exact finite dependency-window account is reported in the [family note](../research/2026-09-14-binary-lift-family.md) and [recursion note](../research/2026-09-14-binary-lift-recursion.md).

The selected encoding depends on the source rule. Prepared transverse axes repeat every four cells and contain only the source line's independent information. There is no claim about arbitrary independently specified 2D input, unique off-image completion, nontriviality from faithfulness alone, or induction over dimension. G preservation at higher floors remains a separate incomplete gate.
