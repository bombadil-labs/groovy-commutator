# Translation rank and causal displacement rank separate available from law-used directions, but remain representation-relative

For a declared lattice state family, `rho_T` measures the free rank of translations that act nontrivially after quotienting translations that fix the whole family pointwise; for a local rule, `rho_C` measures the rank spanned by its essential displacement offsets. Exact controls separate ambient coordinates, per-site storage and channel count: a literal 1D copy inside 2D and any finite anchored track family can remain `rho_T=1`, while taking the translation closure of the track family gives `rho_T=2`. In the accepted ordered-axis ECA constructor, however, `E(G_{r,2})=E_r×E_r`, so the complete 256-rule audit gives target causal ranks `4/4/248` at ranks `0/1/2` and adds no rule classification beyond source essentiality. The ranks are useful representation-relative bookkeeping, not an intrinsic-dimension theorem. See the [relational-rank note](../research/2026-09-12-relational-rank.md).
