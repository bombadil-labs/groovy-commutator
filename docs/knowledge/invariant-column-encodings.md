# Two elementary updates survive the column encoding test

For the fixed ternary 2D interpreter, an injective encoding of each 1D bit by
one of two periodically repeated vertical columns intertwines with an
elementary rule only for Rules 23 or 232 at cadence one. No elementary target
works at cadence two or three. A local-constraint graph establishes this for
every finite vertical height, within this columnwise encoding family.

The finite census contains other invariant code families whose effective
updates require wider neighborhoods. Absence of an elementary target therefore
does not imply loss of all lower-dimensional dynamics. No Class-IV labels or
enrichment were evaluated. See the [experiment](../research/2026-09-08-column-compatibility.md).
