# Local lifts preserve disturbance extent up to bounded thickening

For the phase-aligned ancestral six-field encoding of a radius-one binary CA, root disagreement support A and dimension-d macrocolumn disagreement support B obey A subset B subset A thickened by2(d-1) original-line cells. The same-column decoder proves the first inclusion; finite root-line locality proves the second.

Boundedness and asymptotic linear spreading rates are therefore unchanged at each fixed floor. For stationary pair ensembles, the asymptotic exponential rate of empty disagreement intervals is also unchanged if the limit exists. These are conditional local-recoding statements, not a universal native-child-rule theorem. Raw densities, covariance, component counts and limits where dimension grows with time are not covered.

Materialized checks through6D agree. Empty-interval probabilities on actual D1–D3 recurrences obey the corresponding finite bounds, but pooling active and absorbed epochs can defeat their use as a class discriminator.
