# Can interacting strips retain an exact joint description?

**Partly answered.** At least one background row allows the specified strips
to compose as independent Rule-90 processes. With no separator, physical
cross-influence occurs, but 47 of 64 local inputs leave the existing code
at cadence two. The joint state cannot generally be summarized by the two
familiar logical bits under that code.

The next open test is an enlarged representation retaining the interface
residual as additional state. Specify its degrees of freedom, decoder,
locality, and sampling cadence before testing repeated closure. A successful
one-step readout alone does not establish a recurrent logical organization.

The [composition experiment](../research/2026-09-08-coupled-strips.md) gives exact
interface formulas and failures to build on. Alternate alignments, controlled
separators, and other cadences remain untested options, not refuted proposals.
