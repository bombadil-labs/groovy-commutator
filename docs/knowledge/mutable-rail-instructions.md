# Can introduced Rail instructions themselves become locally editable?

The [spatial program witness](../research/2026-09-09-spatial-rail-programs.md) gives exact recursive typing, local edits of eight ECA leaf bits, and autonomous program transport. Every added Rail wrapper is still fixed by the ambient dimension.

The next bounded extension should give an introduced selector instruction an explicit physical representation and a local edit operation. Count the additional instruction cells, derive the resulting guard and action identities, and freeze the variant before evaluation.

A failed placement or guard condition is evidence about that variant. Preserve it and specify any rescue separately. Reducing the role alphabet or producing the layout autonomously is a different experiment. Class-IV correspondence is background intuition and does not guide this search.
