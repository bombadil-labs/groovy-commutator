# The state-to-rule assignment changes the dynamics

On the default 4×4 selector, horizontal addressing has longest cycle 12 and two fixed points; vertical addressing has longest cycle 4 and 66 fixed points. Rotating both the address and table positions gives conjugate dynamics, verified at every state of both tested tori for 24 assignments.

The coupled ring also depends on its assignment under feedback. Closure of the representation is not encoding invariance. These are exact finite comparisons, not a preferred physical geometry. See [the complete results](../research/2026-09-08-shared-state-rule.md).
