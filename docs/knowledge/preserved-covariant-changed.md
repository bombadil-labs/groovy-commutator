# Preserved, covariant, or changed: classifying a property relative to a transformation

Given a represented dynamics and an admissible transformation `T`, declared with what it transports and what it costs, a property `Π` is **preserved** if `Π(T·) = Π(·)`, **covariant** if `Π(T·) = T_Π(Π(·))` for a stated transport `T_Π` of the property's value, and **changed** otherwise. A covariant property with an unstated transport is the usual way a convention is mistaken for a result. The classification is always relative to a declared transformation; no single group is assumed and no property is called intrinsic. Defined by the [Invariants Across Representation Contracts](../research/2026-09-10-representation-invariants-program.md) program; first applied in the [audit note](../research/2026-09-11-representation-invariants-audit.md).
